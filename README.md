## Features

- Sprinting

- Crouching

- Sliding

- Freelooking

- 4 different guns

- CS:GO-like recoil

- 3 different types of enemies

- Aim down sights

- Double jump

- Dashing

- Grapple Hooks

- Wall gliding

- Wall jumping

- Grenades

- Fall damage

- Ground slamming

- Super jumping

- Melee weapon (Knife)

- Bullet decals

- Speedometer

- Sound effects

- Music

- Smoke grenades

- Flashbangs

- Car

- Explosion VFX

- Ledge grabbing

- Peeking

## Keys

- **WASD / Arrow Keys**: Move

- **Mouse**: Look around

- **LMB**: Shoot

- **RMB**: Aim down sights

- **Space**: Jump

- **Shift**: Sprint

- **Control**: Crouch

- **Alt**: Freelook

- **E**: Change gun

- **X**: Dash

- **N**: Grapple hook

- **G**: Throw grenade

- **Escape**: Open in-game menu

- **F11**: Toggle fullscreen

- **B**: Throw smoke grenade

- **C**: Throw flashbang

- **F**: Enter car

- **W**: Brake

- **A / R**: Peek left / right

## Quick start

### Prerequisites

- [Godot 4.8-dev6](https://godotengine.org/download/archive/4.8-dev6)

### Building / Running from source

1. Clone the repository:
   ```bash
   git clone https://github.com/Enkrypt512/Cool-Movement-Game.git
   ```

2. Open Godot, click **Import**, and navigate to the project folder.

3. Select the `project.godot` file.

4. Press `F5` in Godot to run the game directly.
