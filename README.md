# Cool-Movement-Game
A WIP FPS movement game inspired by ULTRAKILL And Half-Life, made in Godot! With:​

- Sprinting

- Crouching

- Sliding

- Freelooking

- Guns

- CS:GO-Like Recoil

- Controller Support

-  Aim Down Sight

- Double Jump

- Dashing

- Grapple Hooks

And More Coming Soon! Like:

- Bullet Decals

- Peeking

- Multiplayer

- Reloading Animation

- Stages

- Ledge Grabbing

- Melee Weapons

- Wall Gliding

- Wall Jumping

- Smoke & Normal Grenades
