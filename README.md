## Keys

- **WASD / Arrow Keys**: Move

- **Mouse**: Look Around

- **LMB**: Shoot

- **RMB**: Aim Down Sight

- **Space**: Jump

- **Shift**: Sprint

- **Control**: Crouch

- **Alt**: Freelook

- **E**: Change Gun

- **X**: Dash

- **N**: Grapple Hook

- **G**: Throw Grenade

- **Escape**: Open In-Game Menu

- **F11**: Toggle Fullscreen

- **B**: Throw Smoke Grenade

- **C**: Throw Flashbang

- **F**: Enter Car

- **W**: Brake

- **A / R**: Peek Left / Right

## Quick Start

### Prerequisites

- [Godot Engine 4.8.x](https://godotengine.org/download)

### Building / Running from Source

1. Clone the repository:
   ```bash
   git clone https://github.com/Enkrypt512/Cool-Movement-Game.git
   ```

2. Open **Godot Engine**, click **Import**, and navigate to the project folder.

3. Select the `project.godot` file.

4. Press `F5` in Godot to run the game directly.
