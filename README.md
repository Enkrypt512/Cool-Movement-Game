# Cool-Movement-Game
A WIP FPS Movement Game Inspired By ULTRAKILL And Half-Life,Made In Godot!  With:

- Sprinting

- Crouching

- Sliding

- Freelooking

- 4 Different Guns

- CS:GO-Like Recoil

- 3 Type Of Enemies

- Aim Down Sight

- Double Jump

- Dashing 

- Grapple Hooks

- Wall Gliding

- Wall Jumping 

- Grenades

- Fall Damage

- Ground Slamming

- Super Jumping

- Meele Weapon (Knife)

- Bullet Decals

- Speedometer

And More Coming Soon! Like:

- Peeking

- Multiplayer

- Reloading Animation

- Stages

- Ledge Grabbing

- Smoke Grenades

# Keys:

- WASD/Arrow Keys:Move

- Mouse:Look Around

- LMB:Shoot

- RMB:Aim Down Sight

- Space:Jump

- Shift:Sprint

- Control:Crouch

- Alt:Freelook

- E:Change Gun

- X:Dash

- N:Grapple Hook

- G:Throw Grenade

- Escape:Bring Up The InGame Menu

- F11:Toggle Fullscreen
