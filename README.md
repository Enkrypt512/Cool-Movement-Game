# Cool-Movement-Game
A WIP FPS Movement Game Inspired By [ULTRAKILL](store.steampowered.com/app/1229490/ULTRAKILL) And [Half-Life](store.steampowered.com/app/70/HalfLife),Made In [Godot](godotengine.org)! With:

- Sprinting

- Crouching

- Sliding

- Freelooking

- 4 Different Guns

- CS:GO-Like Recoil

- 3 Type Of Enemies

- Aim Down Sight

- Double Jump

- Dashing 

- Grapple Hooks

- Wall Gliding

- Wall Jumping 

- Grenades

- Fall Damage

- Ground Slamming

- Super Jumping

- Melee Weapon (Knife)

- Bullet Decals

- Speedometer

- Sound Effects

- Music

- Smoke Grenades

- Flashbangs​

- Car

- Explosion VFX

- Ledge Grabbing

- Peeking

And More Coming Soon! Like:

- Multiplayer

- Reloading Animation

- Stages

# Keys:

- WASD/Arrow Keys:Move

- Mouse:Look Around

- LMB:Shoot

- RMB:Aim Down Sight

- Space:Jump

- Shift:Sprint

- Control:Crouch

- Alt:Freelook

- E:Change Gun

- X:Dash

- N:Grapple Hook

- G:Throw Grenade

- Escape:Bring Up The InGame Menu

- F11:Toggle Fullscreen

- B: Throw Smoke Grenade

- C: Throw Flashbang

- F: Enter The Car

- W: Brake

- A/R: Peek Left/Right
