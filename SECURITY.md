# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.8.x   | Supported          |
| < 0.8.9 | Unsupported        |

## Reporting a Vulnerability

We take the security of **Cool Movement Game** seriously. If you discover a security vulnerability, flaw, or arbitrary code execution risk, please **do not** open a public GitHub issue.

### How to Report

1. **Private Disclosure:** Report the issue privately using [GitHub Private Vulnerability Reporting](https://github.com/Enkrypt512/Cool-Movement-Game/security/advisories/new) or by contacting the maintainer directly.
2. **Information to Include:**
   - A detailed description of the vulnerability.
   - Steps or proof-of-concept (PoC) code to reproduce the issue safely.
   - Potential impact on users or host systems.

### Response Timeline

- **Acknowledgment:** (should be) Within 48 hours of receipt.
- **Status Update:** (should be) Within 7 days with a plan for remediation.
- **Fix & Public Disclosure:** (should be) A patch will be developed and released in the next patch version before public disclosure.
